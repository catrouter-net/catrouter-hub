Grok 4.7 是什么

Grok 4.7 由 SpaceXAI（xAI） 推出，2026年9月 发布，属于文本类模型。换了更大基座、用更长 RL 周期在“数小时级难题”上重训，主打自我检查与超长上下文管理。

  • 训练取向：官方刻意把训练任务偏向“需要数小时才能完成”的难题，目标是让模型在长任务里少走弯路、少返工。
  • 自我检查：Grok 4.7 显著强化了 self-verification，会在交付前回看自己的产出，这对 Agent 链路是刚需。
  • 上下文管理：长时间运行时的上下文压缩与信息保留能力提升，适合连续数小时的工程与知识工作。
  • 多平台可用：Bedrock、Azure AI Foundry、Cursor 均已上架，企业接入路径清晰，价格被评价为“很有竞争力”。

国内调用会撞上的问题

  • xAI 官方渠道在国内不可直连，多平台（Bedrock/Azure）反而增加配置复杂度。
  • 海外云账号、支付与合规审核门槛高。
  • 长任务场景对连接稳定性要求极高，断线重跑成本大。
  • 不同平台上同名模型的参数支持不一致，切换容易踩坑。

Grok 4.7 中转站怎么接

python · openai sdk
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的Key",
    base_url="https://catrouter.net/v1",
)
client.chat.completions.create(
    model="grok-4.7",
    messages=[{"role": "user", "content": "hi"}],
)

模型 ID 是 grok-4.7，大小写与连字符都要一致。走 Anthropic 原生协议时 base_url 用 https://catrouter.net（不带 /v1）；走 OpenAI 兼容协议用 https://catrouter.net/v1。完整接入步骤见三步接入，报错对照表也在那里。

常见问题

Grok 4.7 最大变化是什么？

不是跑分，而是训练目标转向长时难题与自我检查，Agent 场景的返工率明显下降。

和 4.6 比值得升级吗？

做长程 Agent、专业文档交付值得；只做短问答的话差异不明显。

Bedrock 和直连官方有什么区别？

Bedrock 是企业云通道，计费与配额独立；中转平台则统一成 OpenAI 兼容接口，配置最简单。
