Grok 4.5 是什么

Grok 4.5 由 SpaceXAI（xAI） 推出，2026年上半年 发布，属于文本类模型。Grok 家族的性价比位：响应快、价格低，适合高频对话与轻量 Agent。

  • 速度优势：Grok 4.5 的响应延迟在同价位模型里表现突出，适合聊天、客服、实时问答这类对首字延迟敏感的场景。
  • 价格友好：单价明显低于旗舰档，适合把高频、低难度的调用放到 4.5 上跑，难题再升级到 4.7。
  • 风格特点：回答直接、口语化，对创意写作与社交媒体文案比较友好。
  • 能力边界：超长程 Agent、复杂工程重构仍建议交给 4.7 或更高档模型。

Grok 4.5 中转站怎么接

python · openai sdk
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的Key",
    base_url="https://catrouter.net/v1",
)
client.chat.completions.create(
    model="grok-4.5",
    messages=[{"role": "user", "content": "hi"}],
)

模型 ID 是 grok-4.5，大小写与连字符都要一致。走 Anthropic 原生协议时 base_url 用 https://catrouter.net（不带 /v1）；走 OpenAI 兼容协议用 https://catrouter.net/v1。完整接入步骤见三步接入，报错对照表也在那里。

常见问题

4.5 和 4.7 怎么分工？

高频轻任务用 4.5 控成本，长程难题切 4.7，同一把 Key 直接换模型名。

4.5 支持工具调用吗？

支持基础工具调用，复杂多步编排建议上 4.7。

延迟能降到多少？

取决于中转线路，选国内多节点 + 智能路由的平台首字延迟明显优于跨境直连。
