Kimi K3 是什么

Kimi K3 由 月之暗面 Moonshot AI 推出，2026年7月17日 发布，属于文本类模型。2.8 万亿参数、104B 激活的 MoE，全球首个开源 3T 级模型，原生视觉 + 100 万 token 上下文。

  • 规模突破：K3 参数约为 K2.5 的 3 倍，是全球首个开源的 3T 级模型，在算力不算宽裕的条件下靠架构而不是堆卡实现。
  • KDA 机制：Kimi Delta Attention 混合线性注意力 + Attention Residuals，改善跨序列长度与跨深度的信息流。
  • 原生视觉：不需要外挂视觉编码器，图片理解与长文档版面解析表现更自然。
  • 长程能力：面向长时间编码、知识工作与推理设计，能把一个 prompt 直接变成可玩的游戏、成套 PPT 与交互式研究报告。

国内调用会撞上的问题

  • 官方 API 有配额与并发限制，长上下文调用排队明显。
  • 自建推理 2.8T 级 MoE 门槛极高，中小团队基本不可行。
  • 上下文 1M 时对显存与推理框架要求高。
  • 版本与权重更新快，接口参数变化需要跟。

Kimi K3 中转站怎么接

python · openai sdk
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的Key",
    base_url="https://catrouter.net/v1",
)
client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "hi"}],
)

模型 ID 是 kimi-k3，大小写与连字符都要一致。走 Anthropic 原生协议时 base_url 用 https://catrouter.net（不带 /v1）；走 OpenAI 兼容协议用 https://catrouter.net/v1。完整接入步骤见三步接入，报错对照表也在那里。

常见问题

K3 开源了为什么还要中转？

权重开源不等于能跑，2.8T MoE 的推理成本与工程复杂度极高，按量调用更现实。

K3 和 K2.5 差在哪？

参数约 3 倍、原生视觉、1M 上下文，长程编码与知识工作提升最明显。

1M 上下文怎么用才划算？

先做检索与摘要，再把关键片段送进长上下文，避免整包硬塞。
