GPT-5.4 是什么

GPT-5.4 由 OpenAI 推出，2026年上半年 发布，属于文本类模型。GPT-5 家族里兼容性最好、提示词最稳的一档，很多存量业务至今仍跑在 5.4 上。

  • 稳定性优先：5.4 的提示词行为与工具调用格式在大量生产系统中被长期验证，是“不求最强、只求不炸”的选项。
  • 成本基线：作为五代中前段版本，单价低于 5.5 / 5.6 Sol，适合对质量要求稳定但预算有限的长尾业务。
  • 迁移友好：与 5.5 共用 OpenAI 兼容协议，横向对比只需改模型名，便于做降本实验。
  • 风险提示：部分新能力（如 Fast 模式、超长输出）在 5.4 上不可用，功能规划时要确认版本边界。

GPT-5.4 中转站怎么接

python · openai sdk
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的Key",
    base_url="https://catrouter.net/v1",
)
client.chat.completions.create(
    model="gpt-5.4",
    messages=[{"role": "user", "content": "hi"}],
)

模型 ID 是 gpt-5.4，大小写与连字符都要一致。走 Anthropic 原生协议时 base_url 用 https://catrouter.net（不带 /v1）；走 OpenAI 兼容协议用 https://catrouter.net/v1。完整接入步骤见三步接入，报错对照表也在那里。

常见问题

5.4 会不会被官方下线？

短期内仍在服务，但新特性不再覆盖；建议提前准备好 5.5/5.6 的对照评测。

能直接换成 5.5 吗？

协议兼容，改模型名即可；但输出风格与长度可能有差异，需要重跑评测集。

中转站能同时提供 5.4 和 5.5 吗？

可以，同一把 Key 按模型名切换，便于灰度。
