GPT-5.5 是什么

GPT-5.5 由 OpenAI 推出，2026年4月23日 发布，属于文本类模型。百万 token 上下文、$5/$30 每百万 token 的五代主力，至今仍是大量生产系统的默认模型。

  • 五代主力：GPT-5.5 是 2026 年上半年使用最广的旗舰，提示词体系、评测基线、工具生态都最成熟。
  • 价格选项多：标准 / Fast / Batch / Flex 四种计费形态，可按业务时效性自由组合，批处理场景成本能砍一半。
  • 上下文差异：API 侧 100 万 token，Codex 侧 40 万 token，做长代码任务时要注意入口不同、窗口不同。
  • Fast 模式取舍：1.5 倍速度换 2.5 倍成本，只适合交互式强实时场景。

适合什么活

  • 生产环境通用推理。
  • 批量离线任务（Batch 五折）。
  • Codex 编码工作流。
  • 长文档与知识库问答。

国内调用会撞上的问题

  • 官方接口国内不稳，五代模型调用量大，网络抖动直接转成业务失败率。
  • 海外账号与支付门槛。
  • Batch / Flex 等计费形态在自建代理里很难透传，容易多付钱。
  • 高峰期官方限流，QPS 上不去。

GPT-5.5 中转站怎么接

python · openai sdk
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的Key",
    base_url="https://catrouter.net/v1",
)
client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "hi"}],
)

模型 ID 是 gpt-5.5，大小写与连字符都要一致。走 Anthropic 原生协议时 base_url 用 https://catrouter.net（不带 /v1）；走 OpenAI 兼容协议用 https://catrouter.net/v1。完整接入步骤见三步接入，报错对照表也在那里。

常见问题

GPT-5.5 还有必要用吗？

存量生产系统仍大量依赖它，且 Batch 五折、生态成熟，短期不会被替代。

Fast 模式值得开吗？

只有强实时交互才值得，2.5 倍成本换来 1.5 倍速度，批量任务不划算。

100 万上下文和 Codex 的 40 万冲突吗？

不冲突，是两个入口的不同规格，长代码任务建议走 API 侧。
