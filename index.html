OpenAI 兼容协议与 Anthropic 原生 SDK 都走同一个域名

python · openai sdk
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的中转Key",
    base_url="https://catrouter.net/v1",
)

resp = client.chat.completions.create(
    model="claude-opus-5-5",
    messages=[{"role": "user", "content": "你好"}],
)
# 换模型只改 model= 这一行
bash · curl
curl https://catrouter.net/v1/chat/completions \
  -H "Authorization: Bearer sk-你的中转Key" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-6.1-sol",
       "messages":[{"role":"user","content":"hi"}]}'

其余问题在各自仓库的 README 里

中转站会不会改我的请求内容？

不会。中转只做转发与鉴权，请求参数、thinking block、tool use 都按上游规格透传；返回也是原始响应结构。

为什么同一段文字 token 变多了？

Claude 4.7 之后换了新分词器，官方提示同样文本约多 30% token。做成本测算时不能直接沿用旧版的「字符 × 单价」。

这么多模型，我该从哪个开始？

先看上面的选型助手。默认建议：主力工作用 claude-opus-5-5 或 gpt-6.1-sol，批量与高并发切 haiku-5-5 / v4-flash，出图用 gpt-image-2.6，出视频用 sd-2-5-480p 试稿。
